# Лабораторная работа №1 — последовательное умножение матриц

## Цель работы
Реализовать умножение квадратных матриц на C++17 без распараллеливания, исследовать время выполнения на матрицах разного размера и проверить результаты через NumPy.

## Реализация
Класс `Matrix`: vector<vector<double>>; умножение: метод multiply(), три вложенных цикла в порядке **j-i-k**. Библиотечное умножение в C++ не используется. Исходные матрицы — `A.txt` и `B.txt`, результат — `result.txt`. Формат каждого файла: размер N в первой строке, далее N строк по N чисел.

Для элемента C[i][j] вычисляется сумма произведений A[i][k] × B[k][j]. Оценка числа арифметических операций: около 2N³, памяти для элементов трёх матриц: 24N² байт (без накладных расходов контейнеров).

## Запуск на Windows (Developer PowerShell Visual Studio)
```powershell
cl /EHsc /O2 /std:c++17 main.cpp /Fe:matrix.exe
py -m pip install -r requirements.txt
py generate.py 200
.\matrix.exe
py check.py
py experiment.py --exe .\matrix.exe --sizes 200 400 800 1200 1600 2000
```

## Запуск на Linux
```bash
g++ -std=c++17 -O2 main.cpp -o matrix
python3 -m pip install -r requirements.txt
python3 experiment.py --exe ./matrix --sizes 200 400 800 1200 1600 2000
```

## Методика эксперимента
Для размеров 200, 400, 800, 1200, 1600 и 2000 создаются две матрицы. Для каждого размера запускается последовательное умножение и проверка `check.py` с NumPy. Время измеряется только для умножения, без файлового ввода-вывода. Скрипт `experiment.py` создаёт CSV-таблицу `results/results.csv`, график `results/time_vs_size.png` и обновляет этот раздел README. Для повторных измерений можно указать `--repeats 3`.

## Выводы
Алгоритм последовательно выполняет три вложенных цикла, поэтому его теоретическая сложность O(N³). При росте N время вычисления увеличивается; точный характер роста и различия между вариантами следует оценивать по измерениям на одном компьютере. Корректность вычислений проверяется независимым расчётом NumPy.
